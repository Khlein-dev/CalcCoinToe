# CalcCoinToe
An all-in-one interactive web application that combines three essential tools and a fun game in a single platform

## Features
- A basic calculator for quick arithmetic operations.
- A currency converter for converting between multiple currencies.
- A Tic Tac Toe game for leisure and brain exercise.
